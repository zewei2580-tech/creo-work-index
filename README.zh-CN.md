# Creo 工作文件索引库

适用于 **Windows 64 位、Creo 12 / 13**。

这个工具最初是为减少 Creo 崩溃后的返工而做的：从轨迹恢复开始，经过几个月实际使用，逐渐加入模型卡片、保存节点、工程图、自动保存和项目归类。它不能阻止 Creo 崩溃，但能帮你留下可返回的工作状态。

## 安装与第一次体验

1. 解压后运行 **Setup.exe**。
2. 选择插件目录和索引库目录，可选择电脑上可用的 C、D、E、F 等本地盘。**索引库目录要提前选好**，后续保存节点、备份及导入的项目资料都在这里管理。两个目录须为空，且不能相互包含。
3. 安装器会自动识别 Creo，选中你常用的 **12 或 13 版本**及其启动配置；未识别时可手动选择。
4. 安装完成后，保存工作并正常重启 Creo，看看桌面有没有动态的 **CREO 悬浮入口**。
5. 打开一个测试零件，摆好角度，点击悬浮入口 → **保存当前状态** → **打开索引库**，找到对应卡片，再通过 **CREO打开**返回保存版本。

这是首次安装包，不覆盖已有程序或非空索引库。已有用户应保留原安装和数据，不要为了满足空目录要求而删除旧库。

## 优先使用「保存当前状态」

完成一个阶段、准备修改之前，按需保存最直接。保存后，卡片会更新，并可从下拉列表选择节点。也支持保存 Creo 工程图并关联到对应模型卡片。

自动保存可选 **按变更步数**或**按时间**。按变更默认累计 **5 次有效设计变更保存一次**，次数由系统识别累计，不是鼠标点击数；停着不动 Creo，不会增加设计变更次数。

大型装配、逆向点云或 STL 工作中，保存时的卡顿可能影响建模体验，可以调大间隔，或暂停自动保存，改为按需手动保存。

自动保存只做 **A/B 轮替**，新的保存替代对应旧槽。手动保存的快速节点单独保留；「整理快速节点」只保留最新快速节点，并永久删除确认列表中的旧备份文件。文件占用时可记为待整理，也可取消。普通命名方案、自动 A/B 和工作原件不在这项清理范围内。

## 悬浮入口更直观

原来的 CREO 图标不拉长。开启自动保护后：

- 按次数：右侧只显示 `2/5`。
- 按时间：下方只显示 `01:20/05:00`。

不加额外底框、文字标签或进度条。数字来自插件的实际累计数据；达到间隔仍需等待安全保存条件，不代表已经保存成功。关闭自动保护后隐藏进度。

![进度位置示例，数字为演示数据](floating-approved-right-count-bottom-time-20261022.png)

恢复中心提供 **「打开新模型时询问是否开启自动保存」**开关，默认开启。只询问尚未选择保护策略的模型，同一会话内不反复询问；关闭这个开关不会关掉已经开启的自动保存。

## 每天从卡片继续工作

打开 Creo，再打开索引库，就能查看近期工作。点击卡片上的 **CREO打开**继续处理，不用反复翻文件夹。

整个项目资料文件夹也能拖入对应项目，复制并校验后归档，原文件仍保留。以后从项目卡片直接打开资料文件夹，在导入后的目录继续管理文件。

公开版模型卡片已去掉内部使用的「对比并优化」入口。
