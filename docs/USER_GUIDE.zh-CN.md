## 1. 安装和第一次体验

1. 完整解压安装包，运行最外层 Setup.exe，选择实际 Creo 版本及启动配置。
2. 插件目录与索引库目录分开。首次安装使用空目录；升级选择已识别的现有安装。
3. 保存工作并退出 Creo、索引界面后安装，完成后重新启动 Creo。
4. 新建空索引库默认显示 SP115050 体验样例。先用副本测试打开、保存及恢复。该导入样例标记为未验证，不能冒充已确认正常的操作前快照。

旧节点和现有库不因升级而清空。请另行保留重要项目备份。

## 2. 保存节点

- **快速保存节点**：在当前状态留下一个手动节点。
- **命名节点保存**：填写有意义的名称，例如“改孔距前”。
- **自动保存**：开启后按该文件设置触发，并使用 A/B 两个槽位轮替。
- 修改次数、时间到期或进度提示不代表已经保存成功，要等 Creo 和插件返回结果。
- 保护会受模型保存许可、依赖完整性、未结束编辑及 Creo 状态限制。大型模型可能需要更长时间。

## 3. 选择、打开、改名与删除

![节点卡片](images/v574-card.png)
![展开列表](images/v574-nodes.png)

单击节点选项只是选择预览，不会自动切换 Creo。双击模型预览或点 **CREO打开** 才发起打开请求，并准备独立工作副本。同名模型或子件仍在会话中时可能提示冲突；关闭窗口不一定已经从内存移除模型。

**本地文件**打开所选节点的系统文件夹。目录中的 `_checkpoint.ok`、清单、健康记录和预览是插件数据；不要手动移动、改写或删除，否则可能影响恢复。

**改名**只修改节点名称，不更改零件文件名或节点身份。右键节点列表可锁定、解除重要节点锁定。

- 节点行 **×**：按确认结果将可删除的手动节点移入回收站。
- 卡片 **删除**：处理整组索引备份，可能永久删除、不经回收站；请阅读确认框。
- 被活动会话占用、锁定、直接用于待恢复操作的节点，或删除后没有可确认正常恢复节点时，会限制删除。

## 4. 回收站与清理

索引库顶部 **回收站**显示对应卡片。单选后可“恢复所选”或“清空所选”；“清空全部”处理全部允许清空的条目。清空属于永久删除并会确认。整个项目、模型记录会标明“整项”，其操作范围不是单个节点。

**立即清理**用于预览并清理可确认的失败复制、过期暂存等垃圾；它与回收站清空不同。无法确认安全或仍被使用的内容不会删除。正式保存节点不应当作临时垃圾清理。

## 5. 自动保存设置

![自动保存设置](images/v574-autosave.png)

三种方式择一：按步骤（预设20次有效变更）、按时间（默认5分钟）、修改后静置（预设60秒）。不同模型保存自己的设置；升级保留已有设置。设置页可开启或暂停自动保存，保存设置本身不等于自动开启。

“出错时继续记录问题现场”用于保留问题状态，不代表问题节点可以冒充正常恢复节点。A/B 轮替与正常节点保留按实际模型状态执行。

## 6. 出错保护与恢复最后一次操作

出错保护和自动保存独立。出错保护在支持的编辑入口生成或复用操作前快照，要求模型身份与依赖完整。**保存节点不一定恰好是出错前一步**；只有已验证的操作记录和快照一致时才能按最后一次操作恢复。

受保护操作超过约20秒没有空闲反馈，会提示继续等待或结束会话并恢复。运算时间长不一定是错误；结束会话可能丢失其他未保护模型的未保存修改。模型载入成功也不等于所有特征都正确，请核对模型树、几何和可编辑状态。

## 7. 项目、装配、工程图与副本

项目可用于归类模型卡片及关联资料文件夹；顶部有新建、改名、归入项目和项目备份/迁移入口。导出后请核对包内依赖及目标机读取情况。

卡片可关联工程图、导入 STP。保存装配节点需要已识别的相关原生组件；复杂骨架、外部引用、族表和 Windchill 模型需要另行验收，不能只用顶层文件判断完整。

**新建副本**用于建立独立模型；装配副本以实际组件映射和验证结果为准。首次使用请检查子零件是否独立，避免在未经核对的副本上直接投入正式工作。
